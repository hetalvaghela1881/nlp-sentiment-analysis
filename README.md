# NLP Sentiment Analysis

## Overview

This project implements a Natural Language Processing (NLP) based sentiment analysis system to classify text reviews as positive or negative.

## Technologies Used

- Python
- Pandas
- Scikit-Learn
- TF-IDF Vectorization
- Logistic Regression

## Features

- Text preprocessing
- Feature extraction
- Sentiment classification
- Machine learning model evaluation

## Applications

- Customer feedback analysis
- Product review classification
- Social media monitoring
- Opinion mining
